# Práctica de arrays en PHP

Esta carpeta contiene siete ejercicios sin resolver, basados en el tema de arrays de PHP.

## Cómo empezar

1. Abre MAMP e inicia los servidores.
2. Entra en `arrays` desde el navegador. Si MAMP sirve `C:\MAMP\htdocs`, la dirección será:
   `http://localhost/ariketak/wgzi_ariketak_repaso/arrays/`
3. Abre `index.php` y elige un ejercicio.
4. Edita el archivo PHP correspondiente en tu editor y recarga la página para probarlo.

Cada ejercicio incluye los datos iniciales y las instrucciones. Escribe tu solución en el bloque PHP marcado con `TODO`.
